# 🏠 Rent-home Web App

เว็บแอปจัดเงินค่าเช่ารายเดือนสไตล์ **"Broadsheet"** (หนังสือพิมพ์การเงินสไตล์บรรณาธิการ)
แนวคิด **กระแสเงิน**: ค่าเช่ารับเข้า → แบ่งจัดสรร (ผ่อนบ้าน / ส่วนกลาง / ฉุกเฉิน / ทองคำ / ภาษี) → เหลือเท่าไรเก็บไว้
พร้อม **อัปโหลดรูปสลิปเข้า Google Drive อัตโนมัติ** (ตั้งชื่อไฟล์ตามคอนเวนชันเดิม) แล้วเก็บลิงก์กลับเข้า Google Sheet ให้เอง

> สร้างด้วย **Google Apps Script** จึงเชื่อมกับ Google Sheet + Google Drive ของคุณได้โดยตรง
> ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องเสียค่าโฮสต์ ไม่ต้องตั้งค่า OAuth เอง

---

## ✨ ความสามารถ

- 💸 **จัดเงิน (Dashboard)** — เห็นค่าเช่าที่รับเข้า, แถบแบ่งเงินจัดสรร, ยอดจัดสรร/รอจัดสรร/คงเหลือ ต่อเดือน
- 🗓️ เลื่อนดูย้อนหลังทีละเดือน (ดึงจาก Google Sheet จริง)
- 📷 **บันทึก & แนบสลิป** — เลือกหมวด → กรอกเงิน/วันที่ → ถ่าย/เลือกรูป → อัปโหลดเข้า Drive อัตโนมัติ
- 📋 **ประวัติ** — ทุกเดือนที่บันทึก พร้อมลิงก์ดูสลิป
- 📊 **สรุป** — ยอดรวมรับเข้า/จัดสรรแยกตามหมวดทุกเดือน
- 📱 Responsive — มือถือ (คอลัมน์เดียว + แถบเมนูล่าง) / เดสก์ท็อป (สองคอลัมน์ + เมนูบน)
- 🔒 ข้อมูลยังอยู่ใน Google Sheet เดิมของคุณ 100% (แอปแค่เขียนต่อในชีต)

## 🚀 วิธีติดตั้ง (แนะนำ — คัดลอกวาง ทำครั้งเดียวจบ)

ทำตามนี้ไม่เกิน 5 นาที ไม่ต้องลงโปรแกรมอะไรเพิ่ม

### 1) เปิด Apps Script จากสเปรดชีต
1. เปิด Google Sheet ของคุณ ([ลิงก์ชีต](https://docs.google.com/spreadsheets/d/REDACTED/edit))
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**

### 2) วางโค้ด
ในหน้าต่าง Apps Script ให้สร้างไฟล์ให้ครบ 5 ไฟล์นี้ แล้วคัดลอกเนื้อหาจากโฟลเดอร์ `src/` มาวาง:

| ในโปรเจกต์ Apps Script สร้างไฟล์ชื่อ | เอาเนื้อหาจาก |
|---|---|
| `Code.gs` (มีอยู่แล้ว วางทับได้เลย) | `src/Code.gs` |
| `Index.html` (กด **+ → HTML**) | `src/Index.html` |
| `Stylesheet.html` (กด **+ → HTML**) | `src/Stylesheet.html` |
| `JavaScript.html` (กด **+ → HTML**) | `src/JavaScript.html` |
| `Icons.html` (กด **+ → HTML**) | `src/Icons.html` |

> เวลาสร้างไฟล์ HTML ให้ตั้งชื่อว่า `Index`, `Stylesheet`, `JavaScript`, `Icons` (ไม่ต้องพิมพ์ `.html`)

### 3) ตรวจการตั้งค่า (ไฟล์ `Code.gs` ด้านบนสุด)
```javascript
var SHEET_NAME = 'ข้อมูลหลัก';   // << เปลี่ยนเป็น "ชื่อแท็บ" ที่จะบันทึกข้อมูล
var HEADER_ROW = 2;             // แถวหัวตาราง (ของชีตนี้คือแถวที่ 2)
var DRIVE_FOLDER_ID = 'REDACTED'; // โฟลเดอร์สลิปเดิมของคุณ
```
- **สำคัญ:** ตั้ง `SHEET_NAME` ให้ตรงกับชื่อแท็บล่างสุดของชีตที่ต้องการบันทึก
  (ถ้าใส่ผิด แอปจะใช้แท็บแรกของไฟล์ให้แทน)
- `DRIVE_FOLDER_ID` ตั้งไว้ที่โฟลเดอร์สลิปเดิมของคุณแล้ว รูปใหม่จะไปรวมกับของเก่า
  (ถ้าเว้นว่าง ระบบจะสร้างโฟลเดอร์ `Rent-home Slips` ให้อัตโนมัติแทน)

### 🖼️ การตั้งชื่อไฟล์สลิป
ระบบจะตั้งชื่อไฟล์ให้ตรงกับที่ใช้ใน Drive อยู่แล้ว โดยอิงจาก **วันที่จ่าย** ที่กรอก:

| ประเภท | ตัวอย่างชื่อไฟล์ | ปีที่ใช้ |
|--------|------------------|---------|
| ค่าเช่า | `Rent_2026-07-10.jpg` | ค.ศ. |
| ค่าส่วนกลาง | `ส่วนกลาง_2569-07-17.jpg` | พ.ศ. |
| ผ่อนบ้านเพิ่มเติม | `Bank_2026-07-17.jpg` | ค.ศ. |
| เปลี่ยนนิติ | `ส่วนกลาง_2569-05_เปลี่ยนนิติ.jpg` | พ.ศ. (ปี-เดือน) |

แก้รูปแบบได้ที่ตัวแปร `SLIP_NAMING` ใน `Code.gs`

### 4) เผยแพร่เป็นเว็บแอป
1. กด **Deploy (ติดตั้งใช้งาน) → New deployment**
2. เลือกชนิด (⚙️ ข้าง Select type) เป็น **Web app**
3. ตั้งค่า:
   - **Execute as:** `Me` (ตัวคุณเอง)
   - **Who has access:** `Only myself` (เฉพาะฉัน) — หรือ `Anyone` ถ้าจะเปิดให้คนอื่นใช้
4. กด **Deploy** → ครั้งแรกจะให้ **Authorize / อนุญาตสิทธิ์** ให้กดอนุญาต
   (จะเห็นคำเตือน "Google hasn't verified this app" ให้กด **Advanced → Go to … (unsafe)** ได้เลย เพราะเป็นสคริปต์ของคุณเอง)
5. คัดลอก **Web app URL** ที่ได้ → เปิดในมือถือ/คอมได้เลย 🎉

> 💡 เปิดในมือถือแล้วกด "เพิ่มไปยังหน้าจอโฮม" (Add to Home screen) จะใช้เหมือนแอปจริง

## 🛠️ วิธีติดตั้งด้วย `clasp` (command line)

เวอร์ชันนี้ตั้งค่าให้ deploy เป็นสคริปต์แบบ **standalone** ที่เปิดสเปรดชีตด้วย `SPREADSHEET_ID`
(กำหนดไว้แล้วใน `src/Code.gs`) จึงใช้ `clasp` ได้ทั้งกระบวนการ

**สิ่งที่ต้องทำครั้งเดียวก่อนเริ่ม:** เปิดใช้ Apps Script API ที่
👉 https://script.google.com/home/usersettings (สวิตช์ **Google Apps Script API → On**)

```bash
# 1) ติดตั้ง clasp (อยู่ใน devDependencies แล้ว)
npm install

# 2) ล็อกอินบัญชี Google ของคุณ (เปิดเบราว์เซอร์ให้อนุญาตสิทธิ์)
#    ถ้าอยู่บนเครื่องที่ไม่มีเบราว์เซอร์ ใช้:  npx clasp login --no-localhost
npm run login

# 3) สร้างโปรเจกต์ + อัปโหลดโค้ด + สร้าง deployment ในคำสั่งเดียว
npm run setup
#    (เท่ากับ clasp create → clasp push → clasp deploy)

# 4) เปิดโปรเจกต์เพื่อดู Web app URL / จัดการ deployment
npm run open
```

หลังจากนั้นเข้าไปที่โปรเจกต์ → **Deploy → Manage deployments** เพื่อคัดลอก **Web app URL**
(ครั้งแรกต้องกด **Authorize** อนุญาตสิทธิ์ Sheets + Drive)

> คำสั่งย่อยที่มีให้: `npm run push` (อัปเดตโค้ด), `npm run deploy` (สร้างเวอร์ชันใหม่),
> `npm run login:status` (เช็กว่าล็อกอินด้วยบัญชีไหน)

> **หมายเหตุ:** clasp จะเก็บ token ล็อกอินไว้ที่ `~/.clasprc.json` บนเครื่องคุณ
> และไฟล์ `.clasp.json` (มี scriptId) จะถูกสร้างในโปรเจกต์หลัง `npm run create` —
> ทั้งสองไฟล์ถูกใส่ไว้ใน `.gitignore` แล้ว จะไม่ถูกอัปขึ้น git

## 🔄 อัปเดตโค้ดในภายหลัง

หลังแก้โค้ดแล้ว ให้ **Deploy → Manage deployments → (ดินสอ ✏️) → Version: New version → Deploy**
เพื่อให้ URL เดิมใช้เวอร์ชันใหม่ (URL ไม่เปลี่ยน)

## ❓ ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|------|--------|
| บันทึกแล้วข้อมูลไปผิดแท็บ | ตั้ง `SHEET_NAME` ใน `Code.gs` ให้ตรงชื่อแท็บ |
| คอลัมน์ไม่ตรง | แอปจับคู่คอลัมน์จาก "ชื่อหัวตาราง" อัตโนมัติ ถ้าเปลี่ยนหัวตาราง ให้แก้ `header` ใน `FIELDS` |
| กดดูสลิปแล้วเปิดไม่ได้ | ตรวจว่าการแชร์ไฟล์ Drive เป็น "ผู้ที่มีลิงก์" — บาง Workspace ปิดไว้ ต้องแชร์เอง |
| รูปอัปโหลดไม่ได้ | ไฟล์ต้องเป็นรูปภาพและไม่เกิน 15MB |
